# 🏆 WC 2026 Tracker — Álbum Panini FIFA World Cup 2026

App mobile para trackear tu álbum Panini del Mundial 2026.

## 📱 Instalar en el celular

### iPhone (Safari)
1. Abrí la URL de la app en Safari
2. Tocá el botón **Compartir** ↑
3. Tocá **"Agregar a pantalla de inicio"**
4. Nombre: **WC 2026** → Agregar ✅

### Android (Chrome)
1. Abrí la URL en Chrome
2. Menú **⋮** → **"Agregar a pantalla de inicio"**
3. Confirmá ✅

## 🎨 Personalizar el ícono

1. Creá una imagen PNG de **512×512 píxeles**
2. Renombrala a **`icon.png`**
3. Subila a este repositorio reemplazando el `icon.png` existente
4. ¡Listo! El ícono se actualiza en todos los celulares

### Dónde crear tu ícono gratis:
- **canva.com** → buscá "app icon 512x512"
- **remove.bg** → para sacar el fondo de una imagen
- **favicon.io** → para convertir emojis en íconos

## ✨ Features
- 📚 Álbum Panini completo (48 selecciones × 21 figuritas + FWC + Coca-Cola)
- ✅ Marcar figuritas: tengo / me falta / repetida
- 🔄 Lista de repetidas para WhatsApp
- 📅 Fixture completo con carga de resultados
- 🏆 Tablas de posiciones automáticas
- 🔮 Sistema de pronósticos bloqueados
- 🎊 Celebración con confetti al completar un país
- 💾 Guarda todo en el celular (sin borrado)
